# Synthetic Study Population

A synthetic study population; one row per individual with relevant date
variables

## Usage

``` r
StudyPopulation
```

## Format

\## \`StudyPopulation\` A data frame with 100 rows and 6 variables:

- id:

  identifier for unique individuals

- covid_vaccine_1:

  Date of first COVID-19 vaccine dose (primary anchor date).

- covid_vaccine_2:

  Date of second COVID-19 vaccine dose (optional anchor date).

- start_followup_criteria:

  Date variables relating to the start of the follow up )

- end_followup_criteria:

  Date variables relating to the end of the follow up (end follow up
  dates, death as censoring event dates)
