# Records Table

A synthetic record table; one or multiple row per individual

## Usage

``` r
RecordsTable
```

## Format

\## \`RecordsTable\` A data table with multiple rows per individual and
4 variables:

- id:

  identifier for unique iindividuals

- outcome:

  Identifier of the record related to a specific outcome (e.g.,
  myocarditis or pericarditis).

- date:

  Date variables relating date of the record

- value:

  value of the record
